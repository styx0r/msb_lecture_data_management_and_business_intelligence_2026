Data visualization with Matplotlib
Assume you have a DataFrame with columns year, GDP Line plot GDP over year ``` from matplotlib import pyplot as plt fig, ax = plt.subplots(figsize=(15,4)) # figsize is optional ax.plot(df['year'], df['GDP']) ax.set_xlabel('Year') ax.set_ylabel('GDP') ``` There are many available plot styles, e.g. ``` ax.plot # Line plot ax.bar # Bar plot ax.scatter # Scatter plot ```
Multiple (2) plots with shared x Scale ``` from matplotlib import pyplot as plt fig, ax = plt.subplots(nrows=2, sharex=True, figsize=(15,4)) # figsize is optional ax[0].plot(df['year'], df['GDP']) ax[0].set_xlabel('Year') ax[0].set_ylabel('GDP') ax[1].plot(df['year'], df['Age']) ax[1].set_xlabel('Year') ax[1].set_ylabel('Age') ``` There are many available plot styles, e.g. ``` ax.plot # Line plot ax.bar # Bar plot ax.scatter # Scatter plot ```
